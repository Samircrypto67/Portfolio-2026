Mini-jeu Devinette

Type : Projet personnel (BTS SIO SLAM)

Technologies : JavaScript / HTML / CSS

Objectif

Créer un jeu interactif où le joueur doit deviner un nombre généré aléatoirement.

Principe

Le joueur doit trouver un nombre entre 1 et 100. À chaque tentative, le jeu indique si le nombre est trop grand ou trop petit.

Fonctionnalités

  • Génération d’un nombre aléatoire
  • Saisie utilisateur
  • Messages d’aide (plus grand / plus petit)
  • Compteur de tentatives
  • Fin de partie (victoire ou défaite)

Logique du jeu

const nombre = Math.floor(Math.random() * 100) + 1;

if (userGuess === nombre) {
    message = "Bravo !";
} else if (userGuess < nombre) {
    message = "Trop petit";
} else {
    message = "Trop grand";
}

Le jeu repose sur des conditions, des boucles et des événements JavaScript.

Structure

  • index.html → interface utilisateur
  • style.css → design
  • script.js → logique du jeu

Compétences développées

  • JavaScript (conditions, fonctions)
  • Manipulation du DOM
  • Gestion des événements
  • Création d’un jeu interactif

Résultat

Jeu fonctionnel permettant à l’utilisateur de deviner un nombre avec interaction dynamique.

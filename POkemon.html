Projet Pokémon

Type : Projet personnel (BTS SIO SLAM)

Technologies : JavaScript / HTML / CSS

Objectif

Créer un mini-jeu de combat inspiré de Pokémon avec des interactions dynamiques en JavaScript.

Fonctionnalités

  • Combat joueur vs adversaire
  • Attaques avec dégâts aléatoires
  • Barre de vie dynamique
  • Système de soin
  • Fin de combat (victoire / défaite)

Logique du jeu

Exemple de condition :

if (vie <= 0) {
    finDuJeu();
}

Le jeu utilise des événements (boutons), des fonctions et des conditions pour gérer les actions.

Structure

  • index.html → interface
  • style.css → design
  • script.js → logique du jeu

Compétences

  • JavaScript (logique)
  • Manipulation du DOM
  • Création d’un jeu interactif

Résultat

Jeu fonctionnel avec interactions et affichage dynamique.

Contexte

Développement d’un site web dynamique pour gérer des cours et des utilisateurs.

Objectif

Créer une application web permettant de gérer les utilisateurs et les cours avec une base de données.

Missions réalisées

  • Création d’un site web dynamique
  • Gestion des utilisateurs (CRUD)
  • Connexion à une base de données MySQL
  • Mise en place des rôles (admin / utilisateur)

Fonctionnalités

  • Ajout, modification, suppression d’utilisateurs
  • Gestion des cours
  • Système de connexion

Compétences développées

  • Développement web (PHP)
  • Base de données (MySQL)
  • Gestion des utilisateurs
  • Travail en mode projet

Résultat

Site fonctionnel permettant la gestion des utilisateurs et des cours.
